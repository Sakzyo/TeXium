TeXium 1.0.0 fixes excess vertical space in the right inspector. Empty Outline, Problems, References, History, Notes, and clean Git views now show their guidance at the top, and the Git summary no longer reserves an oversized area above the change list.

The DMG contains an ad-hoc signed, universal arm64/x86_64 app for macOS 14 or later, plus an Applications shortcut.

This developer build is not signed with a Developer ID certificate and has not been notarized. Gatekeeper rejects the artifact, so macOS may block a normal launch after download. It is being published at the maintainer's explicit request for users who understand that limitation.

Validation includes the 73-test core suite, the focused inspector UI test, strict ad-hoc signature verification, a mounted-image content check, architecture and version checks, and DMG verification.
